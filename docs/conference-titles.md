# 日本臨床眼科学会のタイトル

正式イベント名は `第N回 日本臨床眼科学会` とする。直後に併記された `（臨眼 YYYY）` / `(臨眼 YYYY)` は補助略称なので保存しない。括弧・空白の全半角差を許容し、4桁の年のみ対象にする。

共通ヘルパー `scripts/auto-updater/titles.js` を抽出、監査、更新候補判定、保存時に使用する。他学会の括弧、記念大会など正式名称に必要な括弧、共催セミナーの `【臨眼2026】` は変更しない。回次・開催年を推測で変更しない。

既存データの修正対象は第81回（2027年）と第82回（2028年）の2件。第80回は既に正式名称。表示専用の例外は追加せず、全モードで元の正式タイトルを利用する。

## Gemini Monitorの表記差のみの変更

空白・全半角・括弧や句読点だけが異なり、文字内容と順序が同じタイトルは自動適用せず、既存タイトルを保持する。NFKC正規化後に空白と句読点を除いた内容を比較し、括弧内の文字・数字は保持する。学会名、回次、年、括弧内の開催地などの内容が変われば通常のタイトル変更として判定する。

分類時と保存直前の両方で確認する。表記差だけの変更は適用件数に含めず、それだけのバッチではevents.jsへ書き込まない。会場など他項目の変更は独立して扱う。
