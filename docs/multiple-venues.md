# 会場データの登録・更新方針

公式大会ページで複数会場が確認できる場合は、原則として `venues: [{ name, mapUrl }]` に各会場を独立して保存する。地図リンクは各会場名と公式住所から個別に生成する。単一会場は従来の `venue` を使用できる。

表示は `venues` を優先する。PCでは横並び、480px以下では会場ごとに改行し、地図ピンは1個をブロック全体の縦中央に配置する。旧 `venue` は後方互換のため残し、構造化会場の追加時にも変更しない。

巡回では、公式の会場欄の独立した施設名・住所、または同一大会のJSON-LD Event.location配列を根拠とする。所在地や事務局欄は会場として採用しない。スラッシュや曖昧な文章から会場数を推測しない。

抽出した複数会場は既存の会場変更と同様に確認対象とし、確認後に構造化データを適用する。Geminiの自由文の会場推測から配列を生成しない。既存 `venues` は単一会場候補で上書きしない。

回帰対象は第80・81回日本臨床眼科学会、第131・132回日本眼科学会総会。表示テストに加え、複数会場抽出、個別地図リンク、曖昧な会場欄、単一会場、旧データ保持を検証する。
