# 共催製薬会社フィルター

`companies.js` に製薬会社マスターと、ブラウザー／Node.js共通の関数を置く。
医療機器メーカーは今回のマスター・検索対象に含めない。

イベントの既存 `sponsor` 文字列は主催／共催表示とカレンダー出力のために維持する。
確定した共催情報は別途、次の構造で保存する。未確認の場合は `sponsors` を省略できる。

```js
sponsors: [
  { companyId: "santen", role: "co-sponsor" },
  { companyId: "bayer", role: "co-sponsor" }
]
```

主催文字列に会社名が含まれるだけでは共催と推測しない。
今回の既存データ移行は共催として記載された臨眼2026関連セミナーの参天製薬、
ノバルティス ファーマ各1件のみ。マスター外の会社名も既存表示文字列に保持する。

将来Updaterで共催欄を抽出する際は、欄から分離した会社名を
`resolveCompanyId(name)` へ渡す。NFKC、空白、法人格の表記を正規化し、
正式名・略称・aliasesとの完全一致でIDを返す。未知の会社は `null` を返すため、
元の表記をレビュー対象として保持し、自動で近似一致させない。
この変更はUpdaterの抽出／自動適用対象を増やさない。

UIは全イベントデータに明示的な共催実績のある製薬会社のみをマスター順に表示する。
件数はその会社が直接共催するイベント数で、同一イベント内の重複は1件。
親学会への間接一致は件数に加えない。参加予定や他フィルターによる表示件数ではない。
ノバルティス ファーマもマスターに残し、データ上の共催実績が0件ならUIには表示しない。

複数会社はOR、他カテゴリとはAND。親学会は紐づくセミナーの会社でも一致するので、
参加予定を設定する前でも発見できる。親学会自身には地域・年・専門領域・演題募集・
終了済み・非表示等の条件を適用し、関連セミナーは従来どおり親学会が参加予定のときだけ表示する。
