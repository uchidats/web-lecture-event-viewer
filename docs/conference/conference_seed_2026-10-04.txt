OphthalConf 学会データ拡充指示（2026-10-04時点）

目的
- 国内眼科学会を網羅的に管理できるようにする。
- 2026〜2028年の国内主要学術集会と、日本人眼科医が参加しやすい主要国際学会を events.js に追加する。
- 既存のイベントスキーマ、参加予定、parentConferenceId、関連セミナー表示、年フィルター、カレンダー連携を壊さない。
- 公開情報が未定の項目は推測しない。null / "" / "unknown" を使う。
- 同じ学会・同じ年の既存レコードがあれば重複追加せず更新する。
- 既存IDを変更しない。新規IDは安定した規則で生成する（例: conf-jp-jos-2027）。
- abstractSubmission は情報が公式に確認できる場合だけ設定する。未確認は status: "unknown"。
- 学会公式URLが確認できない場合、URLを捏造しない。sourceUrl に日本眼科学会の予定表URLを保持してよい。

========================================
F. 演題募集フィールド
========================================
学会イベントには、可能なら下記を持たせる。

abstractSubmission: {
  status: "open" | "upcoming" | "closed" | "unknown",
  startDate: "YYYY-MM-DD" | null,
  deadline: "YYYY-MM-DD" | null,
  url: string | null
}

注意:
- 公式情報が確認できない場合は必ず unknown。
- deadline を推測しない。
- status は日付から自動算出できるようにしてもよい。
- 将来「演題募集中」「締切30日以内」「締切7日以内」のフィルターに使える設計にする。

2027年日本眼科学会総会は、2026-10-01時点で公式サイトに「演題募集」が掲載済み。
ただし正確な締切日は公式ページを取得して確認してから入力すること。
