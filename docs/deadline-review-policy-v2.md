# Deadline review判定の見直しと2027年前半再監査

2026年10月15日。対象は既存の開催開始日が2027年1月1日〜6月30日の20学会。イベントデータの更新はabstractSubmissionとregistrationだけに限定する。

## 判定

人間判断のreviewは、同一項目の公式情報の矛盾、日時・タイムゾーンの複数解釈、同一イベントを確認できない場合、既存値を置換する根拠が不足する場合に限る。

404・Bot保護・未公開・リンク未検出は取得状態として記録し、既存値を維持する。抽出器が読めないだけのケースはextraction-failedであり、reviewに加算しない。一般演題を募集しないという明示はnot-applicableとする。

共通判定は両巡回経路と対象期間監査で利用する。従来のreviewキュー項目34件は削除せずreclassifiedにし、新たな意味上のreview 3件と取得状態を別に記録する。過去の監査レポートは変更しない。管理UIは人間判断件数と、取得不能・未公開・リンク未検出・抽出失敗を別表示し、状態詳細には採用ボタンを付けない。Gemini監視ログ・UIにもdeadlineStatusesを追加した。

## 正規化と保存

- 既存title normalizationを用いたNFKC・空白・句読点の比較、回次・開催年・同一公式ドメイン・トップページ文脈を利用する。異なる回次や開催年は許容しない。トップからの直接リンク・大会ディレクトリの制約は保持する。
- 年のない終了日は明示年を継承し、年跨ぎを処理する。全体が年省略の場合は同一性を確認した開催回の募集サイクルに合わせる。日付の妥当性と開始終了順を検証する。
- 取消線付き旧期限は既存text処理で除外し、明示された延長期限を採用する。一般演題と指定演題の期間を分離する。
- 英語の締切文章、日英の期間・phase、料金表のEarly Bird / Advance / Standard / Late、前期／後期、早期／事前／当日を処理する。公式ラベルを保持し、区分が不明な場合の事前対象フラグを推測しない。
- 開始日や時刻を必須にしない。日付しか確認できない場合は日付だけ保存し、時刻を作らない。未確認の開始日は追加しない。開始日不明の場合、将来締切だけを根拠に「受付中」を推定しない。
- 不明情報による既存値の削除を防ぎ、同日の既存時刻など正しい精度を保持する。proposalと保存直前に構造・日付を検証し、不正フィールドを保留して他の安全な更新を続行する。
- 登録期間の一部が未抽出の場合、部分的なperiodsで全体を置換しない。今回のAPACRS参加登録は3番目の料金列を完全に抽出できず、既存値を維持した。

画像全般のOCRを実装したものではない。SOEの公式料金表は、実画像で確認した転記をURLとSHA-256に紐づけて保存し、同じ画像のバイト列である場合だけ再利用する。画像が変わった場合は転記を使わず抽出改善対象に戻す。取得はページに実際に掲載された既知の画像に限り、リダイレクト禁止・応答サイズ上限を適用する。画像も共有取得予算に数え、トップに加える取得は合計4件までとする。
