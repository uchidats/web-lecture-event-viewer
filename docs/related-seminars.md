# 関連セミナーの一時停止

関連セミナー（`parentConferenceId` を持つイベント）は、新規収集・追加の対象外とする。公式プログラムの全件収集や、学会ページからのセミナー生成は行わない。既存データは削除しない。

公開画面では `RELATED_SEMINARS_ENABLED = false` により、参加予定の登録済／未登録を問わず一覧・カレンダー・簡易表示から除外する。参加予定や登録日は従来どおり保存する。単独講演会は対象外。

Gemini Monitorは既存のスケジューラで関連セミナーを監視対象から除外しており、新規イベントを生成しない。旧Auto Updaterでもソース巡回・URL探索から関連セミナーを除外する。学会本体の更新は継続する。

将来再開する際は、収集方針を見直したうえで表示フラグを有効化し、保持している親学会と参加予定による連動表示を再利用する。
